Phase 4 — New Features (Thriller Mechanics)
4.1 — Handler Briefings (new widget: handler_message_widget.dart) Each case starts with an incoming "secure message" from your handler — like a text message — that appears on the hacking simulator screen before the phone unlocks. This adds narrative context and urgency. Stored in CaseData as a handlerBriefing field.
4.2 — Revelation Flash (new widget: revelation_overlay.dart) When the player marks the final key clue (clue count hits totalClues), show a 2-second full-screen dramatic flash: "CASE CRACKED" with the clue shown, then automatically offer to go to the Journal. Uses the existing suspenseEvents trigger mechanism — fire a special SuspenseTrigger.caseComplete event.
4.3 — Evidence Connections (new tab in Journal: "Connections") A simple cork-board style view where key clues are shown as cards with lines drawn between connected ones. Read-only, auto-generated from existing keyClueIds. No user dragging required — just visual. Makes the case feel like a real detective wall.
4.4 — Case Rating on Completion CaseCompleteScreen already exists but shows minimal info. Add a scoring panel:
•	Speed (time played vs. par time from CaseData)
•	Accuracy (no red herrings collected → bonus)
•	Hints used (fewer = better)
•	1–3 star rating
Stored per-case in SaveService.
4.5 — Interrogation Screen improvements The InterrogationScreen exists but is underused. For non-tutorial cases: after marking a suspect in Contacts, an "Interrogate" option unlocks. This deepens immersion and makes suspects feel like real people pushing back.
